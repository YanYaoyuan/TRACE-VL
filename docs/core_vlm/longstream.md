# 固定预算长流诊断

本轮验证真正逐步写入、证据离开近期窗口后的问答能力。它是冻结模型的基线/能力实验，不是新训练的记忆架构，也不把CausalPatchPool称为持续记忆。

已核对A100/NAS：旧ActivityNet开发集171个文件全部存在，约2.56 GB，均不足3分钟；原提问时刻后仍可再等待60秒的有15个源视频。OVO开发清单674题中，历史类题有150题的原提问时刻不少于180秒，98题不少于300秒；这些数字是题数，实际选择按源视频隔离。当前未发现该清单600秒以上的问题，首轮不能支持10分钟或小时级声明。

首轮固定8个ActivityNet源视频，每个在原提问时刻、再等待15秒和60秒时回答同一问题；另选8个OVO EPM源视频，在原有不少于300秒的提问时刻回答原问题，总计16个源视频、32次问答。选择按固定哈希排序，在任何新模型输出前完成。延迟为额外等待时间，同时记录实际问题时刻减证据结束的间隔；不在看到参考事件之前提前提问。ActivityNet caption衍生标签尚未通过当前采样帧的视觉审核，这些结果仅作开发诊断。

所有视频只从起点顺序输入一次，2 fps、每两帧一个视觉编码步。FFmpeg逐块输出RGB，不将整个视频像素保留在内存。每步压成4×4空间token。共同近期窗口4步；历史容量32步，比较FIFO和确定种子的reservoir写入，均不接收问题/答案。读取时均匀取4个历史步与4个近期步，最多128视觉token。另报告近期4步、近期8步和纯文本控制。证据位置oracle与存储路由oracle是使用标注的特权诊断，单独列出，不能作为可部署方法。

冻结已完成的Plain LoRA（seed17、2500步）和相同Qwen3.5-4B。真实编码特征保存哈希。问答阶段只用零像素重建原生prompt位置，零像素不进入视觉塔；池化token扩展成常数网格再走原生网格池化，并逐位核对池化值不变。每题使用全新的LM状态，不保留decoder KV。每个工作进程首次真实帧核验原生完整forward，额外验证编码次数单独记录，不混入“一次编码”的业务路径计数。

记录因果帧时间、真实特征哈希、逐题编码次数、历史槽数、固定宽度元数据及特征payload、单步RGB缓冲和实际证据间隔。共享的离线PTS索引、FFmpeg/框架缓冲和模型本身不作为历史记忆；日志落盘仅供审核，策略读取不到日志。此轮不声称测得整个进程严格恒定RSS或部署吞吐。

入口：`scripts/launch_core_longstream_a100.sh`。先执行CPU回归测试、复制选中媒体到`/data`、核验模型/Plain checkpoint/训练视频字节排重；再对一个延迟源视频和一个不少于300秒的OVO源视频做真实问答烟测。烟测4题通过才自动接续固定的16源视频32题计划。原权重、原训练/评测清单和最终测试集不改变，不下载新数据，不启动训练。

结果位于独立`/data/yyy/tracevl-runs/core-longstream-<revision>-001`：`data-audit.json`、`inputs.json`、`smoke-ok.json`、`questions/`、`sources/`、`report.json`、`logs/`及`reports.tar.gz`。本轮点估计用于决定下一步诊断；不会自动晋升架构或启动扩训。

# 有向状态交叉注意力

四组共用冻结的 40K Plain、Qwen 视觉塔、问题、抽帧和候选证据。三个可训练读头共用参数规模、初始权重、训练样本顺序、步数和读取预算。冻结解码器仍传递答案损失梯度。训练使用 A/B 选项交叉熵，评测使用相同的选项 logits。

| 组别 | 历史证据读取 |
|---|---|
| Plain | Qwen 的原始视觉输入和解码 |
| Cross | 对单个有顺序的状态对做普通交叉注意力 |
| Difference | 按对选择，值是两端状态投影差 |
| Antisymmetric | 对称 key 与反对称双线性 value |

新模块挂在中间解码层，只更新用于预测首个答案 token 的提示位置。每对状态来自同一轨迹在不同时间的局部网格特征。两端时间都早于或等于查询时间。视觉缓存独立于语言 KV。一个固定空值候选让读头可以忽略历史。训练前比较完整词表 logits，验证零门控输出与 Plain 相同。训练后评测原顺序与反向证据，并核验空缓存时回到 Plain。固定问题向量时，交换状态保持反对称读头的注意力权重并翻转读出方向。

## A100 启动

从 `research/state-attention-a100` 获取代码，运行 `scripts/launch_state_attention_a100.sh`。脚本使用 `/data/yyy/TRACE-VL/.venv/bin/python`，本地 Qwen3.5‑4B 和 40K Plain 的第 5,000 步检查点。默认输出到 `/nas-data/vlm/yyy/tracevl-runs/state-attention-001`。GPU 数量由 `TRACE_DEVICES=0,1,2,3` 决定，空闲卡较少时会分批。脚本先运行 CPU 回归测试，再缓存一份共享特征，随后并行启动四组，最后生成报告包。

- `TRACE_UPDATES` 默认每个读头 100 步，`TRACE_BATCH` 默认每步 4 个视频问题。
- `TRACE_NATURAL` 可指定自然视频 JSONL。添加或修改样本时，用不同的 `TRACE_OUT`，确保报告可追溯。
- `TRACE_SWANLAB=1` 在结果落盘后回放到已登录的 SwanLab 项目，默认 `trace-vl-core`。
- 失败后用同一命令重跑。完整特征和经哈希验证的已完成组会复用，未完成组按相同种子重跑。
- `REPORT.md` 是结果摘要，`report.json` 带来源组配对区间。回传 `reports.tar.gz` 即可，包内包括逐题预测、曲线和日志。权重保存在各组的 `reader.safetensors`。

分支中的 18 对来自此前签核的帧序样本。脚本复用 ActivityNet 已解压的原片，或从现有的 `0_30_s_activitynetqa_videos_1.tar.gz` 只提取所需 13 段并核对 SHA-256。目录或归档位置不同时，可设置 `TRACE_ACTIVITYNET_ROOT` 或 `TRACE_ACTIVITYNET_ARCHIVE`。它用两个动作段的全帧状态验证工程路径，其中 11 对训练、7 对验证。报告把它记为 `constructed`。对象级结论来自 `natural`，需要另提供真实对向录像和轨迹或框标注。

## 自然视频清单

每行定义一个自然对向样本，包含 `id`、`source_group`、`split`、`question`、`options` 和恰好两个 `views`。用两个自然发生的相反方向片段，不对原视频倒放或重排。两段共用问题与选项，正确选项分别为 0 和 1。路径可相对清单文件。训练和验证按原视频或采集场景隔离。

每个 `view` 含以下字段：

| 字段 | 内容 |
|---|---|
| `video` | 本地视频路径 |
| `span` | 前缀内抽帧区间，单位为秒 |
| `query_time` | 查询秒数，大于或等于区间结束时间 |
| `answer` | 正确选项索引 0 或 1 |
| `tracks` 或 `boxes` | 八组双帧对应的轨迹框或逐步检测框 |
| `visible_steps` | 可选，默认 8。设为 2 时，四组 Qwen 都只直接看最后两个双帧时间步，读头还能读同一共享前缀里缓存的证据 |

`tracks` 使用八个字典，形如 `[{}, {"box-1":[0.1,0.2,0.3,0.4]}, …]`。相同 ID 必须对应同一对象。每个框采用归一化的 `[x1,y1,x2,y2]`，描述该双帧视觉块的区域。若输入的是 `boxes`，格式为八个框列表。关联器使用已经到达的视觉特征进行在线一对一匹配。请用独立于答案的框提供流程，并确保每个视图至少有一个可形成前后对的轨迹。首版接受框或轨迹作为输入。

报告以两个方向都答对为主指标。人工重排结果用于工程验证。自然验证使用配对来源组区间，对比冻结 Plain、Cross 和 Difference。自然集收益未建立时，保留当前对照结果即可。
